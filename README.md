# Student Roster Manager

A Java program that manages student information using object-oriented programming concepts.

## Features

- Creates and manages Student objects
- Stores student names, IDs, GPAs, credit hours, and membership status
- Validates GPA and credit hour values
- Determines class standing based on completed credit hours
- Determines honors eligibility based on GPA and credit hours
- Generates student initials
- Tracks the total number of Student objects created
- Generates a formatted student roster report

## Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes and objects
- Constructors
- Encapsulation
- Getters and setters
- Instance and static methods
- Input validation
- Method overriding with `toString()`

## Technologies Used

- Java

## Files

- `Student.java` — Defines the Student class and its methods
- `RosterManager.java` — Creates Student objects and demonstrates the roster functionality
